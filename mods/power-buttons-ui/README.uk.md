# Мод: power-buttons-ui — явні кнопки «увімк/вимк», що не брешуть і не збиваються

**Гілка:** `mod/power-buttons-ui` · **Основа:** `main` автора · **Залежить від:** нічого
**Платформи:** усі (лише фронтенд) · **Коміти:** 6 (2026-08-03 … 08-05)

[English](README.md) · [Усі моди](../README.md)

## Проблема

- Запуск SteamVR інколи надсилав «спати» замість «прокинутись». Одразу після старту
  програми станції засинали.
- Кнопка живлення групи нічого не робила.
- Станції, що не повідомляють стан, виглядали вимкненими, а один перемикач ніколи не міг їх
  увімкнути (або вимкнути).
- Другий клік під час розкручування (~30 с) надсилав протилежну команду й зупиняв запуск.
- Помилки команд мовчки губилися.

## Причини й виправлення

| Причина | Виправлення |
|---|---|
| `previousSteamVRState` водночас був прапорцем ручного перемикача; ефект спрацьовував і при монтуванні | Окремий стан; реакція лише на справжню зміну стану SteamVR |
| `updatePowerState` групи був порожнім циклом | Зроблено так само, як для однієї станції |
| Стан `-1` (невідомо) вважався «вимкнено» | Окремий стан **невідомо** з нейтральною крапкою (`lib/powerState.ts`) |
| Один перемикач мусить вгадувати напрямок, коли стан невідомий | **Окремі кнопки «увімк» і «вимк»** скрізь (станція, група, заголовок) |
| Сталий 15-секундний кулдаун губив натискання | Блокування лише поки команда виконується |
| Обгортка `ChangeBaseStationPowerStatus` не повертала результат | Повертає. Кнопки показують помилку, автоматика SteamVR лише пише в журнал |

## Переносний рецепт (будь-який інтерфейс для пристроїв зі станом «лише запис»)

- Якщо стан не прочитати, **не робіть перемикач**, зробіть дві явні команди.
- «Невідомо» — окремий стан, і ніколи не «вимкнено».
- Автоматика, що реагує на інший процес (SteamVR), має спрацьовувати лише на **зміну стану**
  цього процесу, а не при монтуванні чи діях користувача.
- Блокуйте повторний запуск, поки команда виконується, а не фіксованим таймером.
- Повертайте помилки бекенду викликачу, а він вирішує, показати їх чи записати в журнал.

## Перевірка

Три натискання «увімк» з інтервалом у кілька секунд доходять усі (у журналі три
`Power command requested`). Старт і стоп SteamVR будять і присипляють станції рівно по разу.
