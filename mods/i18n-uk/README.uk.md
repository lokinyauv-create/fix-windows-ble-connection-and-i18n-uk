## Що робить

Додає `frontend/src/localization/locales/ua.json` і реєструє його в `i18n.js`. Назва
`ua` у виборі мови вже була, просто без перекладу за нею. Файл також містить український текст для рядків, які додають
інші моди («Увімкнути»/«Вимкнути» з power-buttons-ui, сторінку «Кімната» з play-area).
Завдяки цьому жоден із тих модів не залежить від цього, а невикористані ключі нічого не
ламають.

## Переносний рецепт (react-i18next / i18next)

1. Скопіюйте `ua.json` до інших файлів локалізації.
2. `import Ukrainian from './locales/ua.json'` і додайте `ua: { translation: Ukrainian }`
   у `resources`.
3. Якщо у виборі мови є словник назв, додайте `ua: "Українська"`.
4. Ключі — це англійські рядки, тож будь-яка програма з тими самими ключами може взяти
   файл як є.
