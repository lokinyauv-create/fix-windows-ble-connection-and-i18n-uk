# Мод: lighthouse-dfu — оновлення прошивки базових станцій Lighthouse 2.0 з Linux

**Гілка:** `mod/lighthouse-dfu` · **Основа:** `main` автора · **Залежить від:** нічого (окремий інструмент)
**Платформи:** Linux з BlueZ, Python 3 + `dbus_next` · **Коміти:** 1 (2026-09-26)

[English](README.md) · [Усі моди](../README.md)

## Проблема

У станцій з радіопрошивкою 2.2 характеристика живлення дозволяє лише запис, тож жодна
програма не знає, чи станція справді ввімкнулась (див. мод power-state). Оновити їх з Linux
не виходить:

- оновлення зі SteamVR (через радіо шолома Index) **обвалює vrmonitor** з
  `free(): invalid pointer` ([#653](https://github.com/ValveSoftware/SteamVR-for-Linux/issues/653),
  [#709](https://github.com/ValveSoftware/SteamVR-for-Linux/issues/709));
- звичайний Nordic *buttonless* DFU не спрацьовує: Valve спершу вимагає власну
  автентифікацію («LHB-Unlock»), тож команда входу в завантажувач просто висить.

## Рішення (перевірено 2026-09-26 на двох станціях: радіо 2.2 → 2.9.2004771, MCU 1.2 → 1.8)

1. Вийміть живлення станції, **затисніть кнопку на задній панелі** і вставте живлення.
   Індикатор не світиться. Тепер станція видна як **`LHB-DFU`** з адресою MAC+1.
2. Запустіть `python3 tools/lighthouse-dfu/lh_dfu.py dfu`. Він запише підписаний пакет зі
   SteamVR (`tools/lighthouse/firmware/lighthouse_tx_vader/archive/428/
   lighthouse_tx_vader_radio_full_dfu.v2_9_2004771.zip`) приблизно за 2 хв.
3. Станція перезавантажиться сама. Перевірка: `lh_dfu.py info <MAC>`.

Одна станція за раз. Завантажувач перевіряє підпис. Якщо передача обірветься, станція
лишиться в `LHB-DFU`, і повторний `dfu` завершить роботу. Спершу закрийте інші
BLE-програми (наприклад, цей менеджер), бо станція приймає лише одне з'єднання.

## Переносний рецепт

`lh_dfu.py` — повноцінний клієнт Nordic Secure DFU через BlueZ D-Bus (`dbus_next`) з
мінімумом залежностей: select/create/CRC/execute для init-пакета і 4 КБ блоків даних, із
повтором блоку при помилці. Підійде для **будь-якого** пристрою на nRF5 SDK, чий
завантажувач доступний. Змініть `DEFAULT_PACKAGE` і перевірку імені в `cmd_dfu`.
